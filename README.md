# ТОВ «ГЛОБАЛ АГРО ІНВЕСТ» — корпоративний сайт

Презентаційний B2B-сайт агрокомпанії: інформація про компанію, каталог продукції (ПММ, насіння), контактна форма. Це **не інтернет-магазин** — немає кошика, оплати чи особистих кабінетів. Весь контент (тексти, зображення, каталог) редагується менеджером через Sanity Studio без жодних знань коду.

Архітектура та причини вибору технологій — у [`PROJECT_PLAN.md`](./PROJECT_PLAN.md).

## Технології

| Шар | Технологія |
|---|---|
| Фреймворк | Next.js 16 (App Router, Turbopack) |
| Мова | TypeScript |
| Стилі | Tailwind CSS v4 (CSS-first токени в `globals.css`) |
| CMS | Sanity (Studio вбудовано на `/studio`) |
| Форма зв'язку | Route Handler + Resend API |
| Хостинг | Vercel (безкоштовний тариф) |

## Вимоги

- Node.js 20.19+ або 22.12+ (`node -v`)
- pnpm 10 (`corepack enable` увімкне потрібну версію автоматично — див. `packageManager` у `package.json`)

## Встановлення

```bash
pnpm install
cp .env.example .env.local
```

Заповніть `.env.local` — детальний опис кожної змінної нижче. **Сайт працює і без жодного заповненого значення**: без Sanity-проєкту всі сторінки показують вбудований демо-контент українською (`src/lib/demo-content.ts`), а без Resend-ключа контактна форма чесно повідомляє відвідувачу, що наразі недоступна, замість того, щоб мовчки губити повідомлення. Це дозволяє склонувати репозиторій і одразу побачити готовий сайт, перш ніж підключати реальні сервіси.

## Розробка

```bash
pnpm dev
```

Відкрити http://localhost:3000 — сайт, http://localhost:3000/studio — Sanity Studio (адмінка).

## Змінні середовища

Повний список із коментарями — у [`.env.example`](./.env.example). Коротко:

### Sanity CMS

| Змінна | Призначення |
|---|---|
| `NEXT_PUBLIC_SANITY_PROJECT_ID` | ID проєкту з [sanity.io/manage](https://www.sanity.io/manage). Поки порожній — сайт показує демо-контент. |
| `NEXT_PUBLIC_SANITY_DATASET` | Назва датасету, зазвичай `production`. |
| `NEXT_PUBLIC_SANITY_API_VERSION` | Зафіксована дата версії API — не змінювати без потреби (див. коментар в `.env.example`). |
| `SANITY_API_TOKEN` | Токен з правами Viewer, для серверних операцій. |
| `SANITY_REVALIDATE_SECRET` | Довільний рядок (`openssl rand -hex 32`), спільний секрет для вебхука `/api/revalidate`. |

### Контактна форма (Resend)

| Змінна | Призначення |
|---|---|
| `RESEND_API_KEY` | Ключ з [resend.com](https://resend.com). |
| `CONTACT_FORM_TO_EMAIL` | Поштова скринька, куди приходять заявки з сайту. |
| `CONTACT_FORM_FROM_EMAIL` | Адреса відправника — має бути на домені, підтвердженому в Resend. |

### Англомовна версія (Azure AI Translator)

| Змінна | Призначення |
|---|---|
| `AZURE_TRANSLATOR_KEY` | Ключ ресурсу Azure "Translator" ([portal.azure.com](https://portal.azure.com), безкоштовний тариф — 2 млн символів/міс). Без нього англійські сторінки просто показують український текст неперекладеним — сайт не ламається. |
| `AZURE_TRANSLATOR_ENDPOINT` | За замовчуванням підходить для ресурсу типу "Global". Змінюйте лише якщо у порталі Azure для вашого ресурсу вказано інший Endpoint. |
| `AZURE_TRANSLATOR_REGION` | Потрібно лише для ресурсу, створеного в конкретному регіоні (не "Global") — див. поле "Location" в порталі Azure. |

### Сайт

| Змінна | Призначення |
|---|---|
| `NEXT_PUBLIC_SITE_URL` | Канонічний домен без слеша в кінці — використовується в sitemap.xml, canonical-посиланнях, Open Graph. |

## Робота з контентом (для менеджера, без коду)

1. Створіть безкоштовний проєкт на [sanity.io](https://www.sanity.io) (`npx sanity@latest init` у корені репозиторію — запропонує прив'язати існуючий проєкт до цього коду).
2. Впишіть отримані `NEXT_PUBLIC_SANITY_PROJECT_ID` і `NEXT_PUBLIC_SANITY_DATASET` в `.env.local` (локально) та у налаштування проєкту на Vercel (для продакшн-сайту).
3. Відкрийте `/studio` на сайті — увійдіть під своїм акаунтом Sanity.
4. У лівому меню — розділи українською:
   - **Налаштування сайту** — телефон, email, адреса, соцмережі, логотип (одна сторінка на весь сайт).
   - **Головна сторінка**, **Про компанію**, **Контакти** — тексти й зображення відповідних сторінок (теж по одній сторінці кожна).
   - **Категорії продукції**, **Товари**, **Бренди**, **Напрямки бізнесу**, **Переваги**, **Новини** — списки, які можна додавати, редагувати, видаляти й перетягуванням міняти порядок показу.
5. Кожне поле підписане українською з поясненням, що саме туди писати. Зображення завантажуються перетягуванням файлу — Sanity сам підбирає розмір під сторінку.
6. Натискання **Publish** одразу оновлює сайт: вебхук (налаштовується один раз, див. нижче) миттєво скидає кеш саме тієї сторінки, яку змінили.

### Що станеться, якщо категорію/товар видалити чи перейменувати slug

Адреса сторінки (`slug`) — частина URL (`/products/nasinnya`). Sanity не дає зберегти однакову адресу для двох різних категорій чи товарів (перевіряється автоматично), але зміна адреси після публікації "ламає" вже розповсюджені посилання (на них показуватиметься сторінка 404) — тому поле саме так і підписано в Studio.

### Резервна копія контенту

Контент живе в Sanity, а не в git. Регулярний бекап:

```bash
npx sanity dataset export production ./backup.tar.gz
```

(підставте назву свого датасету замість `production`, якщо змінювали).

## Англійська версія сайту

Сайт двомовний: `/` (без префіксу) — українська, `/en/...` — англійська. Менеджер **завжди пише лише українською** в Sanity Studio — англійська версія кожної сторінки перекладається автоматично (Azure AI Translator) і кешується, тож повторного перекладу тієї самої фрази не відбувається. Перемикач мови — у шапці сайту (праворуч від навігації, і в мобільному меню).

Що саме перекладається автоматично: заголовки, описи, текст сторінок, характеристики товарів. Що **ніколи** не перекладається (і не повинно): назва компанії, назви брендів, телефон/email/адреса, slug-и (адреси сторінок) — це юридичні факти та ідентифікатори, а не текст для локалізації.

Кожна англійська сторінка має непомітну примітку внизу («This page was machine-translated from Ukrainian») — це чесно і потрібно з юридичної точки зору, а не хитрість SEO.

Якщо `AZURE_TRANSLATOR_KEY` не задано, англійські сторінки просто показують український текст без перекладу — сайт не падає і не показує помилку відвідувачу.

Оновлення в Sanity (нова назва товару, змінений опис) автоматично скидають і кеш перекладу цього ж поля — вебхук `/api/revalidate` (вже описаний нижче) працює однаково для обох мов, без додаткового налаштування.

## Контактна форма — як це працює

- Клієнтська валідація (миттєвий фідбек) і серверна валідація (`src/app/api/contact/route.ts`, Zod) — незалежні; сервер ніколи не довіряє тільки клієнту.
- Захист від спаму без CAPTCHA: приховане honeypot-поле + перевірка, що форма заповнена не швидше, ніж це можливо для людини.
- Базовий rate-limit на IP (5 запитів / 10 хв на "теплий" серверний інстанс) — деталі й свідомі обмеження підходу описані в `src/lib/rate-limit.ts`.
- Якщо `RESEND_API_KEY`/адреси не налаштовані — відвідувач отримує чесне повідомлення про тимчасову недоступність форми з проханням зателефонувати, а не тиху відповідь "успішно" без фактичного надсилання.

## SEO та продуктивність

- `sitemap.xml` і `robots.txt` генеруються автоматично (`src/app/sitemap.ts`, `src/app/robots.ts`) з реального списку категорій/товарів/новин.
- Структуровані дані (JSON-LD): `Organization` на кожній сторінці, `Product` на сторінці товару — без вигаданих фактів (наприклад, немає `offers`/ціни, яких ми не маємо).
- Зображення з Sanity ресайзяться на льоту через CDN Sanity (`src/lib/sanity/image-loader.ts`), без окремого сервісу оптимізації зображень.
- Поки в Sanity немає жодного товару/категорії з реальною фотографією, замість неї показується згенерована іконка-заглушка (`src/components/ui/PlaceholderArt.tsx`) — це навмисне рішення, щоб не показувати випадкові стокові фото, які не відповідають реальному асортименту.

## Деплой (Vercel)

1. Запуште репозиторій на GitHub/GitLab.
2. Створіть проєкт на [vercel.com](https://vercel.com) → Import Repository.
3. Пакетний менеджер: Vercel сам визначить pnpm за `pnpm-lock.yaml`.
4. Environment Variables → додайте всі змінні з `.env.example` з реальними значеннями (окрім `NEXT_PUBLIC_SITE_URL`, який вкажіть як фінальний домен).
5. Deploy.

### Підключення домену

Vercel → Project Settings → Domains → додати свій домен і виставити DNS-записи, які покаже Vercel (зазвичай A/CNAME на реєстраторі домену). Після підтвердження оновіть `NEXT_PUBLIC_SITE_URL` на продакшн-домен.

### Вебхук миттєвого оновлення контенту

Без нього оновлення в Sanity теж з'являться на сайті (максимум за годину — фоновий revalidate), але з вебхуком — одразу після Publish:

1. [sanity.io/manage](https://www.sanity.io/manage) → ваш проєкт → API → Webhooks → Create webhook.
2. URL: `https://<ваш-домен>/api/revalidate`
3. Trigger on: Create, Update, Delete.
4. Secret: те саме значення, що й `SANITY_REVALIDATE_SECRET` у Vercel.

## Усунення несправностей

| Симптом | Причина / рішення |
|---|---|
| На сайті показуються демо-товари (ПММ, насіння) замість своїх | `NEXT_PUBLIC_SANITY_PROJECT_ID` не заданий або невірний — перевірте `.env.local`/Vercel env vars. |
| Зміни в Studio не з'являються на сайті одразу | Вебхук `/api/revalidate` не налаштований або секрет не збігається — див. розділ вище. Без вебхука зміни з'являться протягом години. |
| Контактна форма пише "тимчасово недоступна" | `RESEND_API_KEY`/`CONTACT_FORM_TO_EMAIL`/`CONTACT_FORM_FROM_EMAIL` не задані на Vercel. |
| Лист від форми не приходить, хоч форма каже "надіслано" | Перевірте, що `CONTACT_FORM_FROM_EMAIL` — на домені, підтвердженому в Resend (Resend відхиляє листи з непідтверджених доменів без явної помилки для відвідувача сайту — дивіться логи функції на Vercel). |
| `/studio` не відкривається / біла сторінка | Перевірте `NEXT_PUBLIC_SANITY_PROJECT_ID`/`NEXT_PUBLIC_SANITY_DATASET` і що ви залогінені в потрібний акаунт Sanity. |
| Англійські сторінки (`/en/...`) показують український текст | `AZURE_TRANSLATOR_KEY` не задано або невірний — сайт навмисно не падає в цьому випадку (fallback на оригінал), перевірте змінну на Vercel. |
| Локальна збірка (`pnpm build`) не може завантажити шрифти Google Fonts | Мережеве обмеження вашого середовища (проксі/файрвол блокує `fonts.googleapis.com`) — не стосується самого коду; на Vercel та більшості CI це працює без додаткових налаштувань. |
